# Описание блок-схемы создания транзакции

Блок-схема описывает алгоритм обработки запроса на создание финансовой транзакции в приложении SmartWallet. Процесс включает валидацию входных данных, проверку существования счетов, определение типа транзакции (Income, Expense, Transfer, Adjustment), проверку лимитов расходов и сохранение изменений в базе данных. При нарушении любого из условий выполнение завершается с соответствующим HTTP-статусом ошибки.
