# Описание диаграммы архитектуры

Диаграмма иллюстрирует многослойную архитектуру приложения SmartWallet: слой API (контроллеры, AutoMapper, фильтр исключений), слой бизнес-логики (сервисы, JWT-провайдер, хешер паролей, калькулятор), слой доступа к данным (репозитории, Unit of Work, EF Core) и PostgreSQL как базу данных. Связи показывают направление зависимостей между компонентами.
