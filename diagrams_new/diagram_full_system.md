# Описание диаграммы полной системы

Диаграмма отображает архитектуру полноценного веб-приложения SmartWallet: пользователь взаимодействует через мобильный браузер с React SPA фронтендом, который коммуницирует по HTTPS/JSON с ASP.NET Core Web API бэкендом. Бэкенд обрабатывает запросы через контроллеры и сервисы, использует репозитории для доступа к PostgreSQL, а также интегрирован с Hangfire для выполнения фоновых задач.
