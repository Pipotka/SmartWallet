# Генератор тестовых транзакций SmartWallet

Скрипт для генерации реалистичных тестовых данных транзакций расходов (Expense) и загрузки их в базу данных PostgreSQL. Предназначен для разработки и тестирования проекта SmartWallet.

## Архитектура

Данные разделены на три уровня:

| Источник | Что хранится |
|---|---|
| `.env` | Параметры подключения и генерации (USER_ID, DAYS_BACK и т.д.) |
| База данных | Список хранилищ и категорий расходов пользователя (таблица `TransactionEndpoint`) |
| `categories_config.json` | Диапазоны сумм, веса, сезонные паттерны и якорные события для каждой категории |

При запуске скрипт подключается к БД, загружает конечные точки транзакций пользователя, сопоставляет их с настройками из `categories_config.json` по имени категории и формирует конфигурацию генерации.

### Модель генерации

Скрипт использует гибридную мультипликативную модель для расчёта суммы каждой транзакции:

```
final_amount = base_amount × seasonal_multiplier × weekday_multiplier × random_noise
```

| Множитель | Описание |
|---|---|
| `base_amount` | Случайная сумма из диапазона `[min, max]` категории |
| `seasonal_multiplier` | Синусоидальная волна в рамках месяца: `1 + amplitude × sin(2π × (day - phase) / period)` |
| `weekday_multiplier` | Множитель дня недели (будни/выходные) |
| `random_noise` | Случайный шум из `noise_range` (по умолчанию ±15%) |

Алгоритм итерации: для каждого дня перебираются все категории. Для каждой категории:
1. Если день совпадает с `anchor_day` — генерируется якорная транзакция с фиксированной суммой.
2. Иначе вычисляется вероятность появления транзакции (вес / tx_per_day, скорректированная множителем выходных).
3. Если транзакция генерируется — рассчитывается сумма по формуле выше.

## Требования

- Python 3.9+

## Установка

```bash
cd scripts
pip install -r requirements.txt
```

## Конфигурация

### Переменные окружения (`.env`)

| Переменная | Описание | По умолчанию |
|---|---|---|
| `USER_ID` | UUID пользователя, для которого генерируются транзакции | `f2c591a7-1cdd-4e60-ba92-95ae351ca1d5` |
| `DAYS_BACK` | Количество дней в прошлое от сегодня (0 = только сегодня) | `365` |
| `TRANSACTIONS_PER_DAY` | Примерное количество транзакций в день | `12` |
| `DB_CONNECTION_STRING` | Строка подключения к PostgreSQL | Пусто (заполните вручную) |

### Формат строки подключения

Поддерживаются оба формата:

**Формат .NET/Npgsql** (как в `appsettings.json`):
```
Host=localhost;Port=5432;Database=smartwallet;Username=postgres;Password=postgres
```

**Формат libpq** (нативный для psycopg2):
```
host=localhost port=5432 dbname=smartwallet user=postgres password=postgres
```

Скрипт автоматически конвертирует формат .NET в формат libpq.

### Конфигурация категорий (`categories_config.json`)

Файл `categories_config.json` содержит настройки диапазонов сумм, весов вероятности, сезонных паттернов и якорных событий для каждой категории. Категории сопоставляются с данными из БД **по имени**.

**Поля верхнего уровня:**

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `default_expense_range` | [float, float] | — | Диапазон сумм для категорий без явной настройки |
| `default_expense_weight` | int | — | Вес вероятности по умолчанию |
| `default_seasonal_amplitude` | float | 0.2 | Амплитуда сезонных колебаний по умолчанию (0.0–1.0) |
| `default_seasonal_period_days` | int | 30 | Период сезонной волны в днях |
| `default_seasonal_phase_day` | int | 1 | День месяца пика сезонной волны |
| `default_weekday_multiplier` | float | 1.0 | Множитель будних дней по умолчанию |
| `default_weekend_multiplier` | float | 1.0 | Множитель выходных дней по умолчанию |
| `salary_day` | int | 5 | День зарплаты (зарезервировано для Income) |
| `salary_amount` | float | 80000 | Сумма зарплаты (зарезервировано) |
| `noise_range` | [float, float] | [0.85, 1.15] | Диапазон случайного шума |
| `categories` | object | — | Словарь настроек по имени категории |

**Поля категории (все опциональны, наследуются от `default_*`):**

| Поле | Тип | Описание |
|---|---|---|
| `min`, `max` | float | Диапазон базовой суммы |
| `weight` | int | Вес вероятности |
| `seasonal_amplitude` | float | Амплитуда сезонных колебаний (0.0–1.0) |
| `seasonal_period_days` | int | Период волны в днях |
| `seasonal_phase_day` | int | День месяца пика волны |
| `weekday_multiplier` | float | Множитель будних дней |
| `weekend_multiplier` | float | Множитель выходных дней |
| `anchor_day` | int | День месяца якорной транзакции (1–31) |
| `anchor_amount` | float | Фиксированная сумма якорной транзакции |

**Пример конфигурации:**

```json
{
  "default_seasonal_amplitude": 0.2,
  "noise_range": [0.85, 1.15],
  "categories": {
    "Продукты": {
      "min": 300, "max": 2000, "weight": 5,
      "seasonal_amplitude": 0.3, "seasonal_phase_day": 8,
      "weekday_multiplier": 1.0, "weekend_multiplier": 1.1
    },
    "Жилье": {
      "min": 15000, "max": 25000, "weight": 1,
      "anchor_day": 5, "anchor_amount": 20000
    },
    "Развлечения": {
      "min": 300, "max": 3000, "weight": 3,
      "seasonal_amplitude": 0.4, "seasonal_phase_day": 12,
      "weekday_multiplier": 0.5, "weekend_multiplier": 1.8
    }
  }
}
```

Если категория из БД не найдена в `categories_config.json`, скрипт использует значения `default_*` и выводит предупреждение.

## Использование

### Генерация и вставка данных

```bash
# Генерация за год (~4380 транзакций) и вставка в БД
python seed_transactions.py

# Генерация только за сегодня (~12 транзакций)
DAYS_BACK=0 python seed_transactions.py

# Генерация за 2 года
DAYS_BACK=730 python seed_transactions.py
```

### Предварительный просмотр (без записи в БД)

```bash
# Показать, какие SQL-запросы будут выполнены
# Примечание: подключение к БД всё равно требуется для загрузки категорий
python seed_transactions.py --dry-run
```

### Очистка перед вставкой

```bash
# Удалить все транзакции пользователя, затем вставить новые
python seed_transactions.py --clear

# Без запроса подтверждения (для CI/CD)
python seed_transactions.py --clear --yes

# Предварительный просмотр очистки + вставки
python seed_transactions.py --clear --dry-run
```

## Распределение транзакций

Скрипт генерирует только транзакции типа **Expense (трата)** (Type=1). Количество и суммы транзакций определяются вероятностной моделью с учётом сезонности, дня недели и якорных событий.

### Паттерны категорий

| Категория | База | Вес | Сезонность (пик) | Будни | Выходные | Якорь |
|---|---|---|---|---|---|---|
| Продукты | 300–2 000 | 5 | 0.3 (8-е число) | 1.0 | 1.1 | — |
| Транспорт | 40–250 | 4 | 0.15 (15-е число) | 1.2 | 0.4 | — |
| Развлечения | 300–3 000 | 3 | 0.4 (12-е число) | 0.5 | 1.8 | — |
| Здоровье | 200–2 500 | 2 | 0.25 (20-е число) | 1.0 | 1.0 | — |
| Жилье | 15 000–25 000 | 1 | — | 1.0 | 1.0 | 5-е число, 20 000 |
| Образование | 500–5 000 | 1 | 0.2 (1-е число) | 1.0 | 0.3 | — |
| Одежда и обувь | 800–6 000 | 1 | 0.35 (10-е число) | 0.8 | 1.5 | — |
| Новая категория | 200–2 000 | 1 | — | 1.0 | 1.0 | — |

Все временные метки генерируются в часовом поясе **Europe/Moscow** в диапазоне 08:00 — 23:00.
