# Тесты
## Юнит тесты
- Название теста должно соответствовать следующему паттерну "<Название тестируемого метода>Should<Ожидаемый результат>";
- Если тестируемый метод являетя асинхронным и в его названии есть постфикс Async - не добавляй этот постфикс в название теста и в summary;
- Пиши summary к тестам. summary должно начинатся с названия тестируемого метода без постфикса Async. После названия метода нужно написать какой результат ожидам получить в этом тесте;
- Тест должен быть разделён на секции Arrange, Act и Assert используя комментарии, например: "// Arrange". Между прямыми слешами и названием секции должен быть пробел;
