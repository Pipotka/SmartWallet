Нужно добавить метод в контроллер FinancialAnalyticsController для получения линейного графика трат по категориям. 

метод должен принимать следующие данные: дата начала, дата окончания, TimeUnit, TimeUnitCount. Диапазон должен вычислятся на стороне сервера автоматически по аналогии с методом сравнительного анализа.

# Валидация
если TimeUnitCount > 1
дата начала не может быть позже даты окончания.
Если TimeUnit - год: TimeUnitCount должен быть не больше 25 лет
Если TimeUnit - месяц: TimeUnitCount должен быть не больше 12 месяцев(год)
Если TimeUnit - день: TimeUnitCount долже быть не больше одного месяца(31 день)
